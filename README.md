# MeAgain Growth Audit

**Live → https://eddieatadapty.github.io/meagain-flow-rebuild/**

Five ideas to turn more MeAgain users into subscribers, each built into a clickable version of MeAgain's own onboarding. Prepared by Adapty.

| # | Idea | Potential outcome |
| :-- | :-- | :-- |
| 01 | Put their plan in the paywall headline | +15–20% CR to purchase |
| 02 | Clear the road to the paywall | +10–15% CR to purchase |
| 03 | Let Capy hand over the plan | +5–15% CR to purchase |
| 04 | Show the 36K ratings while they wait | +5–10% CR to purchase |
| 05 | Catch the people who close it | +10–15% ARPU |

Every price, rating and feature comes from MeAgain's App Store listing, website or in-app screens. Impact ranges are Adapty’s expected effect from teardowns and A/B tests across 30,000+ subscription apps, not measured lift for MeAgain. They overlap, so they don’t add up.

Static single page, no build step: `python3 -m http.server`.
